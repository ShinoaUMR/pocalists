# 📸 K-Pop Photocard Collection

A React app to organize and track your K-Pop photocard collection.

## ✨ Features
- 📱 Responsive grid view
- 🔍 Search by member or group
- 🏷️ Filter by status (Owned/Wishlist/Trade/Sold)
- 📊 Collection statistics (total, owned, value)
- ➕ Add cards instantly
